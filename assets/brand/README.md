# assets/brand

Arquivos gerados — **não edite à mão**. Fonte em `source/` (vetor do mascote + Baloo 2 ExtraBold, OFL).
Regerar: `pnpm brand:build`. O web serve esta pasta em `/brand/*`; o mobile usa cópias em `apps/mobile/assets/`.

| Arquivo | Uso |
|---|---|
| `logo-completa` | Ícone com fundo degradê limão → turquesa e decoração |
| `logo-sem-fundo` | Só o hipopótamo (fundo transparente) |
| `logo-mono` | Uma cor (petróleo escuro), para impressão |
| `logo-icone` | Reduzido: sem brilhos, bolhas e dentinhos soltos |
| `logotipo` | Ícone + "Sorriso na Escola" (texto em curvas) |
| `icon-*.png`, `icon-maskable-512.png` | Favicon, PWA, app |
| `sorriso-marca.zip` | Pacote completo |
